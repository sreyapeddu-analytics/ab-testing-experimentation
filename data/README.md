# Data

## `experiments.csv` (~3 MB, 60,000 rows)

Synthetic A/B experiment log. **No real users — every row was generated by `src/generate_data.py` with `random_state=42`.**

| Column | Type | Description |
|---|---|---|
| `experiment_id` | string | `exp1_checkout_cta`, `exp2_onboarding`, or `exp3_pricing_page` |
| `user_id` | string | Unique synthetic user id (scoped per experiment) |
| `variant` | string | `control` or `variant` |
| `converted` | int (0/1) | Binary outcome (conversion / activation); for exp3, 1 = made a purchase |
| `revenue` | float | Revenue in USD (0 for non-buyers; only meaningful for exp3) |
| `assignment_date` | datetime | Day the user was assigned (2026-10-01 → 2026-10-14) |

### Design truth table (what the generator intended)

| Experiment | Arms | Control truth | Variant truth | Expected read |
|---|---|---|---|---|
| exp1_checkout_cta | 10,000 / 10,000 | 12.0% conv | 13.3% conv | Significant win |
| exp2_onboarding | 10,000 / 10,000 | 34.0% activ | 34.35% activ | Null result |
| exp3_pricing_page | 10,150 / 9,850 | ~$4.20 RPV | ~$4.79 RPV | Win, but SRM flagged |

To regenerate: `python src/generate_data.py` (from the repo root).
